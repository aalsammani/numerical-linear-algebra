Numerical Linear Algebra: Theory, Algorithms, and Computation#

These are the lecture notes and computational laboratories for a one-semester graduate course in numerical linear algebra. The course develops the algorithms at the core of scientific computing, namely the solution of linear systems, least-squares problems, and eigenvalue and singular value problems. For each algorithm it treats three questions together: what the mathematics guarantees, what happens in floating-point arithmetic, and how the method behaves in practice on real data.

Each chapter has two parts that are meant to be used together.

  • The notes develop the theory: definitions, theorems with proofs, derivations of algorithms, their cost and stability, worked examples, and exercises. The notes are also available as a PDF.

  • The lab notebook is an executable Jupyter notebook. It implements the algorithms of the chapter from scratch where that is instructive, checks the implementations against NumPy and SciPy, and runs the experiments that confirm (or delimit) the theory. Several chapters add a case study on a public dataset.

Every notebook page on this site has a download button and launch buttons for Binder and Google Colab, so you can run and modify the code yourself.
